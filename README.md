# Apotik ZRDN STR WSN - Web Farmasi

Aplikasi web profil dan katalog obat sederhana untuk **Apotik ZRDN STR WSN** menggunakan PHP native dan styling berbasis layout tabel dengan pemanfaatan Flexbox.

## 💊 Fitur Utama
- **Halaman Utama (`home.php`)**: Menampilkan katalog produk obat-obatan yang tersedia (Kapsul Racikan, Bodrex Tablet, dan Amoxicillin 500mg) dalam bentuk tampilan kartu (*card*) yang responsif.
- **Halaman Profil (`profil.php`)**: Menyajikan informasi mengenai sejarah singkat, visi, serta misi dari Apotik ZRDN STR WSN.
- **Halaman Kontak (`kontak.php`)**: Menyediakan detail kontak operasional (Alamat, WhatsApp, Jam Kerja) serta formulir interaktif bagi pelanggan untuk menanyakan ketersediaan stok obat.

## 🛠️ Teknologi yang Digunakan
- **PHP** (Native)
- **HTML5**
- **CSS3** (Menggunakan kombinasi layout tabel dan CSS Flexbox untuk penataan elemen)
